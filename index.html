📱 安装到手机桌面

方式1：下载APK安装（推荐）
  1. 点击上方"安卓下载 APK"按钮
  2. 下载完成后，打开APK文件
  3. 允许"安装未知来源应用"
  4. 按照提示完成安装
  5. 从桌面图标启动游戏！

方式2：添加网页到桌面
  1. 点击"网页版游戏"进入游戏
  2. 点击浏览器右上角 ⋮ 菜单
  3. 选择"添加到主屏幕"
  4. 桌面将出现游戏图标
Safari浏览器：
  1. 点击"网页版游戏"进入游戏
  2. 点击底部分享按钮 ⎋
  3. 向下滑动，选择"添加到主屏幕"
  4. 点击右上角"添加"
  5. 桌面将出现游戏图标，全屏体验！

注：苹果系统不支持APK安装包，请使用网页版。
